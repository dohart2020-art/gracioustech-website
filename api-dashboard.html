API Documentation

API endpoint

https://iknhifndgpwibkfidggq.supabase.co/functions/v1/gracioustech-api

Request headers

Content-Type: application/json
x-api-key: YOUR_API_KEY

Example 1: NIN Verification

{
  "service": "nin_verification",
  "verification_type": "by_nin",
  "nin": "CUSTOMER_NIN"
}

Example 2: BVN Verification

{
  "service": "bvn_verification",
  "bvn": "CUSTOMER_BVN"
}
These are example request formats. Replace the placeholder values with authorized test data. Never publish real customer NIN or BVN information.

Example JavaScript request 

const response = await fetch(
  "https://iknhifndgpwibkfidggq.supabase.co/functions/v1/gracioustech-api",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "x-api-key": "YOUR_API_KEY"
    },
    body: JSON.stringify({
      service: "nin_verification",
      verification_type: "by_nin",
      nin: "CUSTOMER_NIN"
    })
  }
);

const result = await response.json();
console.log(result);
Do not put a private provider API token or Supabase service-role key in this page. Only use your developer API key in requests from your application.
