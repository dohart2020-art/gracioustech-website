How to Use the API

Send requests to your deployed GRACIOUSTECH API Edge Function. The example below demonstrates the request format for NIN verification.

Request method: POST

Request headers:

Content-Type: application/json
x-api-key: YOUR_API_KEY

Request body:

{
  "service": "nin_verification",
  "verification_type": "by_nin",
  "nin": "CUSTOMER_NIN"
}

Endpoint:

https://iknhifndgpwibkfidggq.supabase.co/functions/v1/gracioustech-api
Replace the example values with valid data only when you are authorized to perform the verification. Do not use real identity numbers in public demonstrations or screenshots.

The request fields and service names must match the deployed API gateway. Do not assume a service is available merely because it appears on this dashboard.
